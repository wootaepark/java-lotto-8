## ✅ 기능 요구 사항

- [x] 로또 구입 금액을 입력받는다.
- [x] 입력 금액이 숫자가 아닌 형태인 경우 예외처리를 한다.
- [x] 로또 구입 금액은 1000원 단위로 입력받으며, 1000원으로 나누어떨어지지 않으면 예외처리
- [x] `구입금액 / 1000원 = 로또 구입 개수` 정보를 출력한다. (상수(1000원)는 하드 코딩 하지 않는다.)
- [x] 구입 개수 만큼의 랜덤 로또 번호를 오름차순으로 정렬하여 출력한다.
- [x] 당첨번호 6개를 입력받는다. (`,` 를 기준으로 구분)
- [x] 보너스 번호 1개를 입력받는다.
- [x] 당첨 번호 정보와 보너스 번호 정보를 가지는 인스턴스를 생성한다. (생성 시, 당첨 번호와 보너스 번호의 중복 여부 판단 )
- [ ] 당첨 통계를 `당첨 기준` 을 기반으로 출력한다.
- [ ] 수익률을 출력한다. (소수점 둘째자리에서 반올림)
- [ ] 위 기능 요구사항은 수정될 수 있다.

## 개발 하면서 생긴 추가 요구 사항

- [ ] 구매 금액 음수 처리
- [ ] 예외 발생 이유가 여러개인 경우 -> 여러 예외 메시지가 동시에 출력되도록 (^^;; 해보자)
- [x] 입력 받는 로또 우승 번호의 중복 여부 확인하기 List 로 받고 중복 검사 후 Set 자료구조로 변경

## ✅ 당첨 기준

```
1등: 6개 번호 일치 / 2,000,000,000원
2등: 5개 번호 + 보너스 번호 일치 / 30,000,000원
3등: 5개 번호 일치 / 1,500,000원
4등: 4개 번호 일치 / 50,000원
5등: 3개 번호 일치 / 5,000원
```
