# java-lotto-precourse

---

## ✅ 기능 요구 사항

- [x] 로또 구입 금액을 입력받는다.
- [ ] 로또 구입 금액은 1000원 단위로 입력받으며, 1000원으로 나누어떨어지지 않으면 예외처리
- [ ] `구입금액 / 1000원 = 로또 구입 개수`  만큼 구입한 로또의 번호를 오름차순 정렬하여 출력한다.
- [ ] 당첨번호 6개를 입력받는다. (`,` 를 기준으로 구분)
- [ ] 보너스 번호 1개를 입력받는다.
- [ ] 당첨 통계를 `당첨 기준` 을 기반으로 출력한다.
- [ ] 수익률을 출력한다. (소수점 둘째자리에서 반올림)
- [ ] 위 기능 요구사항은 수정될 수 있다.

---

## ✅ 당첨 기준

```
1등: 6개 번호 일치 / 2,000,000,000원
2등: 5개 번호 + 보너스 번호 일치 / 30,000,000원
3등: 5개 번호 일치 / 1,500,000원
4등: 4개 번호 일치 / 50,000원
5등: 3개 번호 일치 / 5,000원
```
